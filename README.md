# Netflix Data Analysis - Power BI

Welcome to my first GitHub repository! This project focuses on analyzing the Netflix dataset to uncover insights about movies, TV shows, and viewership trends using *Power BI*.

## 📊 Project Overview
This interactive dashboard provides a comprehensive look at Netflix's content library. The main goals of this analysis were to understand:
* *Content Distribution:* Breakdown of Movies vs. TV Shows.
* *Rating Analysis:* Distribution of content across various age ratings.
* *Release Trends:* Tracking how much content was added to Netflix over the years.
* *Geographical Insights:* Identifying top-performing countries in terms of content production.

## 🛠 Tools & Technologies
* *Power BI Desktop:* Used for data cleaning, modeling, and visualization.
* *Data Source:https://d.docs.live.net/2D1D0C484F103C5C/Documents/netflix.xlsx.
* *DAX (Data Analysis Expressions):* Used for creating custom measures and KPIs.
